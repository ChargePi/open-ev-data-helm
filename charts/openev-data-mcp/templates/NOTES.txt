Database:
{{- if .Values.postgresql.cnpg.enabled }}
  A dedicated PostgreSQL cluster is managed by CloudNativePG (Cluster/{{ include "mcp.postgresClusterName" . }}).
  This requires the CloudNativePG operator's CRDs to already be installed in the cluster:
    helm repo add cnpg https://cloudnative-pg.github.io/charts
    helm upgrade --install cnpg-operator cnpg/cloudnative-pg --namespace cnpg-system --create-namespace
{{- else }}
  Using the external database at {{ .Values.postgresql.external.host }}:{{ .Values.postgresql.external.port }},
  credentials from Secret/{{ .Values.postgresql.external.existingSecret }}.
{{- end }}
{{- if .Values.migration.enabled }}
  Schema + seed data were applied by a post-install Job that fetched
  migrations/001_initial.sql from ChargePi/openev-data-mcp@{{ include "mcp.migrationGitRef" . }}.
  This only runs once, on install — bump mcp.image.tag and re-run manually
  (kubectl apply / helm template | kubectl apply -f -) to pick up a newer migration.
{{- end }}
